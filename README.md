# داروخانه آفلاین

مرجع دارویی کاملاً آفلاین برای مرور، جستجو و بررسی داروهای فهرست رسمی ایران — بدون نیاز به اینترنت،
سرور، یا هیچ سرویس خارجی.

## هدف پروژه

فراهم‌کردن یک ابزار جستجوی سریع و قابل‌اعتماد برای داروهای موجود در فهرست رسمی کشور، غنی‌شده با
داده‌های تکمیلی (کلاس دارویی، دسته‌بندی درمانی، شرح فارسی، تداخل دارویی) از منابع باز و معتبر
بین‌المللی، در قالبی که هم برای عموم و هم برای کادر درمان قابل استفاده باشد.

## دیتابیس پایه

منبع اصلی، فهرست رسمی دارویی ایران (سامانه IRC، سازمان غذا و دارو) است:
https://irc.fda.gov.ir/Home/HomePage

هر رکورد شامل این فیلدهاست:

| فیلد | توضیح |
|---|---|
| `name_en` | نام رسمی دارو (انگلیسی، همان‌طور که در فهرست IRC ثبت شده) |
| `molecule_en` | ترکیب دارویی کامل به همراه مقدار هر جزء |
| `strength` | قدرت دارویی |
| `form_en` / `form_fa` | شکل دارویی |
| `route_en` / `route_fa` | نحوه مصرف/راه تجویز |
| `atc` | کد ATC (طبقه‌بندی جهانی WHO) |
| `index_code` | کد فهرست رسمی دارویی کشور |
| `access` | سطح دسترسی: `otc` (بدون نسخه) · `rx` (نسخه‌دار عادی) · `hospital` (فقط بیمارستانی) |
| `biologic` | فرآورده بیولوژیک بودن |
| `entry_date_j` | تاریخ ورود به فهرست (تقویم شمسی) |

فهرست رسمی IRC فقط ساختاری است و شامل نام فارسی، موارد مصرف بالینی، عوارض یا هشدار نیست. این
اطلاعات از منابع تکمیلی زیر افزوده شده‌اند.

## منابع داده تکمیلی

| لایه | منبع | مجوز |
|---|---|---|
| نام و معادل فارسی (`fa.name`، `fa.aliases`) | فرهنگ دستی داخلی بر پایه ماده مؤثره، برای تقریباً همه داروهای فهرست | — |
| شرح فارسی/بالینی (`fa.uses` و ...) | دیتابیس دستی داخلی، تدوین‌شده برای حدود ۹۹۰ داروی پرکاربرد | — |
| خلاصه انگلیسی موارد مصرف (`intl`) | [eg-drugs](https://github.com/mahmoudfalous/eg-drugs) | نامشخص در ریپو |
| کلاس دارویی (`pharm_class`) | [FDA NDC Directory](https://open.fda.gov/apis/drug/ndc/) | Public Domain |
| گروه‌بندی درمانی ATC (`atc_fa`) | استاندارد [WHO ATC/DDD](https://www.whocc.no/atc_ddd_index/)، با کمک ساختار [Codigos-ATC-ANMAT](https://github.com/psbella/Codigos-ATC-ANMAT) | استاندارد باز |
| تداخل دارویی (`data/interactions.js`) | [DDInter 2.0](https://ddinter2.scbdd.com) | CC BY-NC-SA 4.0 |
| فونت رابط کاربری | [Vazirmatn](https://github.com/rastikerdar/vazirmatn) | SIL Open Font License 1.1 |

منابع اضافی بررسی‌شده که ساختار مشابه دارند و می‌توانند در توسعه‌های بعدی استفاده شوند:

- [Egyptian Drug Database](https://github.com/karem505/egyptian-drug-database) — CC0
- [openFDA](https://github.com/FDA/openfda) و [FDA NDC Directory](https://open.fda.gov/apis/drug/ndc/download/)
- [RxNorm](https://www.nlm.nih.gov/research/umls/rxnorm/index.html)
- [DailyMed](https://dailymed.nlm.nih.gov/dailymed/)
- [DrugBank Open Data](https://go.drugbank.com/releases/latest#open-data)

## محدودیت‌های شناخته‌شده

- **نام فارسی** معادل رایج ماده مؤثره است (نه نام تجاری ثبت‌شده‌ی هر شرکت). شرح فارسی بالینی فقط برای بخشی از داروها وجود دارد؛ برای بقیه، خلاصه انگلیسی، کلاس دارویی و دسته‌بندی ATC به فارسی نمایش داده می‌شود.
- **دوز دقیق مصرف** عمداً در دیتابیس نیامده، چون تعیین آن به شرایط فردی بیمار (سن، وزن، عملکرد
  کلیه/کبد، سایر داروها) بستگی دارد و باید توسط پزشک یا داروساز مشخص شود.
- **تداخل دارویی** فقط برای داروهایی نمایش داده می‌شود که نامشان با نام‌گذاری بین‌المللی DDInter
  تطبیق پیدا کند.

## افزودن یا اصلاح یک رکورد

هر رکورد در `data/drugs-irc.js` آبجکتی با ساختار زیر است:

```js
{
  id: 99999,
  index_code: 9999,
  name_en: "EXAMPLE DRUG",
  molecule_en: "EXAMPLE MOLECULE 10 mg",
  strength: "10 mg",
  form_en: "TABLET", form_fa: "قرص",
  route_en: "ORAL", route_fa: "خوراکی",
  atc: "A00AA00",
  access: "otc",
  biologic: false,
  entry_date_j: null
}
```

## سلب مسئولیت پزشکی

اطلاعات این برنامه جنبه‌ی عمومی و آموزشی دارد و جایگزین نسخه پزشک، مشاوره داروساز یا برگه اطلاعات
رسمی دارو نیست. پیش از هرگونه تغییر در مصرف دارو حتماً با پزشک یا داروساز مشورت کنید.
